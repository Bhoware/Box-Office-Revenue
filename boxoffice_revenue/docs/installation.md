# Installation

## Stable release

To install Boxoffice_revenue, run this command in your terminal:

```sh
uv add boxoffice_revenue
```

Or if you prefer to use `pip`:

```sh
pip install boxoffice_revenue
```

## From source

The source files for Boxoffice_revenue can be downloaded from the [Github repo](https://github.com/Bhoware/boxoffice_revenue).

You can either clone the public repository:

```sh
git clone https://github.com/Bhoware/boxoffice_revenue
```

Or download the [tarball](https://github.com/Bhoware/boxoffice_revenue/tarball/main):

```sh
curl -OJL https://github.com/Bhoware/boxoffice_revenue/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd boxoffice_revenue
uv sync
```
